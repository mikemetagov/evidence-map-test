# About and citation

The Blockchain for Impact Funding Evidence Map is produced by Metagov with support from the GSR Foundation.

## How to cite
Cooper, M. (2026). *Blockchain for Impact Funding Evidence Map* (Version 0.1) [Data set and website]. Metagov. Add the site address or DOI here.

## Contact
Add a contact email or a link to the repository's Issues page for corrections and new evidence.

## Suggest a case or correction
Open an issue in the GitHub repository with the case name, a public link and the outcome it relates to.
