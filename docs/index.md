# Blockchain for Impact Funding Evidence Map

!!! warning "Mock data"
    Every case on this site is invented to test the layout. Replace the files in `data/` with coded pilot or full-study data before sharing.

This site maps what is known, and not known, about how blockchain changes the delivery and governance of impact funding. Each use case is coded by what the blockchain does and which outcomes it affects. Each outcome is graded by the strength of the evidence behind it.

## What the map shows

- **Rows** are blockchain functions, such as payments or registries.
- **Columns** are outcome domains, such as speed or cost of delivery.
- **Bubble colour** is the evidence grade, from claims only (1) to experimental (5).
- **Bubble size** is the number of distinct use cases.
- **Empty, hatched cells** are evidence gaps.

A use case appears once for every outcome it was coded on, so one case can appear in several cells with different grades.
