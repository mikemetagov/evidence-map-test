# Explore the evidence map

Hover over or tab to a bubble to preview the use cases behind it. Click a bubble to pin its card, then follow the links to the case material and the evidence source. Press Esc to close.

<div id="egm" class="egm" data-src="map-data.json"></div>

!!! note "Reading the counts"
    The summary counts distinct use cases. Each bubble counts use cases with that grade for that outcome. Totals across cells can exceed the number of use cases because one case can be coded on several outcomes.
